Alignment Editor

Load an already computed aligment that has been exported from the Align Texts page. It has to be saved first. Due to security restrictions in your browser you cannot save directly, but must first copy the text by clicking on the OK button, then you must create a text file in a text editor (NOT a word processor!), paste in the text and save it. Then you can reload it here for editing. When saving your work in the alignment editor the same process must be followed.

To edit an alignment there are four buttons:

  • Mark: Select some text on one side and click mark. The text must all be either deleted or added. It then gets a grey background. Now select the exact same text on the other side, and click Mark again. It will also go grey. This tells the editor which text you wish to align.
  • Unmark: this button removes any marking in the editor and lets you start from scratch.
  • Remove: This removes the alignment from the selected text. If the alignment runs beyond the selection it is also removed there.
  • Align: This tries to align the marked text. If the two sides are not equal you will get an alert. In this case you must Unmark and start again.

When you are satisfied, click Save to export the alignment. Click OK to copy to the clipboard and save it in a TEXT file.
